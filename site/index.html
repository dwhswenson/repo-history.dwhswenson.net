Repository history

Explore how open source GitHub repositories evolve over time, through their commits, issues, pull requests, and contributors.

This site brings together monthly activity reports and interactive visualizations for several repositories. Compare activity across months, explore cumulative trends, and follow contributor growth.

Open source tools

The reports and visualizations are built with dwhswenson/repo-history:

  • repo-history: a Python tool for collecting GitHub activity and generating monthly reports and summary manifests.
  • repo-history-viz: an embeddable web component for exploring activity and contributor histories on any static website.

The Python package will be released on PyPI soon, and the visualization package will be released on npm soon. In the meantime, source code and installation instructions are available in the GitHub repository above.
